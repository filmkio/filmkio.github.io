# FilmKio — GitHub Pages

صفحهٔ مستقل فارسی معرفی و دانلود فیلمکیو، به‌روز شده در ۱۱ اکتبر ۲۰۲۶.

## انتشار

محتویات این پوشه را در ریشهٔ مخزن `filmkio/filmkio.github.io` قرار دهید؛ پوشهٔ اضافی دور فایل‌ها نباشد. فایل `.nojekyll` را هم منتقل کنید. در تنظیمات GitHub Pages، شاخهٔ انتشار و مسیر `/ (root)` را انتخاب کنید. برای انتشار نیازی به نصب وابستگی یا اجرای build نیست؛ خروجی آماده است.

این بسته هنوز روی گیت‌هاب یا سایت اصلی منتشر نشده است. برای ریشهٔ `filmkio.github.io` طراحی شده، نه زیرمسیر یک project page.

## نگهداری

- نسخه‌ها، مسیر دانلودها، متن معرفی، دادهٔ ساختاریافته و بخش‌های اصلی: `scripts/build.py`.
- متن راهنماهای نصب: `content/install-guides.json`.
- منبع استایل اختصاصی همین صفحه: `assets/site.css`.
- بازسازی خروجی‌های HTML، JavaScript، متادیتای نسخه‌ها و مسیرهای دانلود: `python3 scripts/build.py` (بدون وابستگی).
- `index.html`، `assets/site.js`، `releases.json` و `download/*/index.html` خروجی هستند و با اجرای build بازنویسی می‌شوند. `releases.json` گزارش نسخه‌های زمان ساخت است، نه خوراک به‌روزرسانی برنامه.

## دانلود و دامنه‌ها

لینک‌های دانلود رابط، root-relative هستند (`/download/android/` و مانند آن). چون GitHub Pages فایل‌های WordPress را ندارد، هر مسیر یک صفحهٔ انتقال به فایل رسمی با آدرس `https://filmman.icu` دارد. لینک دستی نیز برای مرورگرهایی که انتقال را انجام نمی‌دهند موجود است. آدرس‌ها از Host دلخواه، query string یا هدر ورودی ساخته نمی‌شوند. هیچ لینک امضاشدهٔ موقت یا دامنهٔ API در خروجی وجود ندارد.

PKGBUILD، RSS و SHA-256 از مسیر رسمی زنده دریافت می‌شوند؛ نسخهٔ ثابت این توصیفگرها در این مخزن ذخیره نشده است. فایل‌های نصبی حجیم در بسته قرار ندارند؛ لینک رسمی آن‌ها قرار دارد.

## محتوا و سازگاری

نسخه‌های تأییدشده: Android 3.9.3، Android TV 2.9، Windows/macOS 1.5.3، Linux 1.5.3-2 (آزمایشی). ال‌جی و سامسونگ از مرورگر استفاده می‌کنند و برنامهٔ بومی قابل نصب معرفی نشده است. تصاویر نمونهٔ مک برای لینوکس و اندروید تی‌وی برای مرورگر تلویزیون با برچسب مشخص شده‌اند.

HTML فارسی RTL و Flexbox؛ بدون CSS Grid، flex gap، display:contents یا aspect-ratio. فونت و تصاویر محلی هستند. عکس اولیه eager با اولویت بالا و عکس پایین صفحه lazy است. بدون JavaScript نیز همهٔ لینک‌های دانلود و راهنماها دیده می‌شوند. نسخهٔ روشن جداگانه در این صفحهٔ مستقل تعریف نشده است.

## بررسی

Chrome: عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰؛ بدون سرریز افقی. هر شش انتخاب دستگاه، پنج راهنمای نصب، پیوند مستقیم راهنما، پرسش‌های بازشونده، ۹ مسیر محلی دانلود و حالت بدون JavaScript بررسی شدند. مقصد ۹ لینک رسمی پیش از تغییر دامنه با HTTP 200 بررسی شده بود؛ دامنهٔ دانلودها سپس به درخواست مالک به filmman.icu تغییر کرد. تست نصب فایل‌ها، تلویزیون فیزیکی و داده‌های میدانی LCP انجام نشده است.

نسخه‌ها و راهنماها در ۲۰۲۶-۱۰-۱۱ بررسی شده‌اند. تصاویر از ZIP ارائه‌شدهٔ مالک و فونت‌ها از قالب فیلمکیو هستند؛ انتقال این دارایی‌ها با همان مجوز پروژه انجام شود.

حجم خام CSS: از 4,974 بایت inline به 12,100 بایت فایل مستقل (3,318 بایت gzip) رسیده است؛ افزایش برای شش دستگاه، چیدمان واکنش‌گرا، انتخاب راهنما، دسترس‌پذیری و بخش مرورگر تلویزیون است. این عدد، اثبات بهبود LCP نیست. استایل فقط متعلق به همین صفحهٔ مستقل است و فایل‌های CSS قالب وردپرس تغییر نکرده‌اند.
